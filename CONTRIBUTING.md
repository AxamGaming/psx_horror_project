# Contributing

Thanks for helping with this project. This is a Godot horror prototype focused on PSX-style presentation, enemy AI, and tense first-person exploration. Contributions are welcome whether you are fixing gameplay issues, improving the AI, adding polish, or refining the project structure.

## How to contribute

There are a few good ways to help:

- fix bugs or improve gameplay feel
- clean up scripts, scenes, or project structure
- improve enemy behavior or level design
- add or refine audio and visual polish
- improve testing and documentation
- help organize project notes or architecture docs

## Before you start

- Open the project in Godot 4.7.x
- Make sure the project runs before submitting a change
- Keep changes focused on one issue or feature at a time
- Prefer small, readable patches over broad rewrites

## Development workflow

1. Fork the repository or create a feature branch.
2. Make a small, targeted change.
3. Test the relevant behavior in Godot.
4. Keep the project in a runnable state.
5. Submit a pull request with a clear summary.

## Pull request guidelines

Please keep pull requests easy to review:

- include a short explanation of the change
- describe why the change is needed
- mention any gameplay or technical tradeoffs
- keep commits concise and relevant
- avoid unrelated formatting churn

A good PR usually includes:

- a brief summary
- what changed
- how it was tested
- any notes for reviewers

## Coding and project conventions

This project is built in Godot using GDScript. Please aim for:

- clear variable and function names
- readable scene/script organization
- minimal unnecessary dependencies
- compatibility with the existing project structure
- behavior that matches the horror prototype’s tone and pacing

## Testing

Please test your changes in the editor before submitting:

- open the project and run the main scene
- check the affected gameplay loop
- verify no obvious regressions in movement, camera, or AI
- test audio and visual effects if your change touches them

For project-specific notes, check the documentation in the README folder and docs folder.

## Reporting issues

When reporting a bug or issue, include:

- what happened
- what you expected to happen
- steps to reproduce
- relevant scene, script, or file names
- your Godot version
- OS and hardware details if relevant

## Questions

If you are unsure whether a change fits the project, open an issue or start a discussion before doing a large rewrite. It is better to align early than to submit a large patch that conflicts with the project direction.

## Respecting assets and attribution

This project includes external assets and references. Please check existing documentation before reusing or redistributing third-party content. Do not assume all files are free to use outside the project context.

## Thanks

Contributions help this horror prototype become more playable, more stable, and more interesting. Thank you for taking the time to improve it.
