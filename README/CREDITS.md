# Audio Credits

Downloaded sounds are **Creative Commons 0** (public domain) from Freesound.
Delivered as silence-trimmed mono **WAV** (converted from the CC0 MP3 previews with
ffmpeg) — compressed formats carry decoder priming padding that makes one-shots
land late against gameplay events; WAV is sample-exact.
Synthesized sounds were generated procedurally in-project (no external source).
